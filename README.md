# RoboSpeaker 🎙️

RoboSpeaker is a beginner-friendly Python project that demonstrates **text-to-speech (TTS)** using the `pyttsx3` library.  
It allows you to type any text in the terminal and hear it spoken aloud.

---

## 🚀 Features
- Converts typed text into speech instantly
- Simple command-line interface
- Adjustable speech rate and volume
- Exit option to quit gracefully

---

## 📦 Requirements
- Python 3.x
- `pyttsx3` library

Install dependencies:
```bash
pip install pyttsx3
